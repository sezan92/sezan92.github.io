## Model and why do we need it?

Before starting about model, let's think what kind of learning algorithms we have encountered till now.

Dynamic programming : where we need complete environment model before training the algorithm. In this case we run the full episode of the environment and then use the actual state , action, reward and the next states.
TD learning method: where we only use samples to train the model. We do not need to wait till the end step.

Here is the thing. Both have advantages and disadvantages! If you know the model of the environment, it would be very easy to train the RL based model using the model!
